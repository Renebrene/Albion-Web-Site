Roadrunner API — Документация для AI-агентов

ROADRUNNER Модуль программной дороги для 3D-баннера «Светофорные объекты» на главной странице Альбион.

Структура

backend/roadrunner/
├── api/
│   ├── schema.json          # JSON Schema для сценариев
│   ├── events.json          # Словарь событий (20 действий)
│   ├── scenarios/           # Готовые сценарии (JSON)
│   ├── API.md               # Markdown-документация
│   ├── PROMPT.md            # Промпт для LLM-генерации
│   └── roadrunner-api.html  # Этот HTML-документ
├── config/                  # Конфигурация (city, weather, traffic, holidays)
├── data/                    # Кэш (погода, пробки)
├── scenario/
│   └── engine.py            # Движок сценариев
├── services/
│   ├── weather.py           # Сервис погоды (Open-Meteo)

JSON Schema для сценариев

{
  "id": "string (uuid-like, lowercase)",           // Уникальный id сценария
  "name": "string (1-100 chars)",                   // Название
  "description": "string (0-500 chars)",            // Описание
  "duration": "integer (30-3600)",                  // Длительность в секундах
  "version": "string (default: '1.0')",            // Версия
  "created_at": "ISO-8601 datetime",                // Дата создания
  "author": "string (1-100 chars)",                 // Автор
  "tags": ["string"],                               // Теги
  "events": [                                       // События (упорядочены по t)
    {
      "t": "number (>= 0, секунды от начала)",
      "do": "string (event name из events.json)",
      "params": "object"
    }
  ]
}

Промпт для LLM-генерации (api/PROMPT.md)

Ты — генератор сценариев для 3D-анимации программной дороги «АЛЬБИОН».

Твоя задача — генерировать JSON-сценарии на основе описания пользователя.

Формат сценария:
{
  "id": "unique-id",
  "name": "Название сценария",
  "description": "Описание",
  "duration": 120,
  "version": "1.0",
  "created_at": "ISO-8601",
  "author": "user",
  "tags": ["tags"],
  "events": [
    {"t": 0, "do": "event_name", "params": {...}},
    ...
  ]
}

Доступные события (do):
- start_traffic, stop_traffic
- change_traffic_density (density: 0.1-3.0)
- change_speed (factor: 0.1-3.0)
- add_car, remove_car (color, type)
- add_bus, remove_bus (route, number)
- add_pedestrian, remove_pedestrian (direction: left/right/cross)
- change_traffic_light_phase (phase: green/yellow/red, intersection: 0-1)
- change_weather (condition: clear/cloudy/rain/snow/fog)
- start_rain, stop_rain (intensity: 0-1)
- start_snow, stop_snow (intensity: 0-1)
- change_time_of_day (phase: morning/day/evening/night)
- add_holiday_decor, remove_holiday_decor (type: trees/snowman/snow/flowers/flags/balloons/confetti/stars)
- end

Правила:
1. Сценарий должен быть логичным и последовательным.
2. Длительность — 30-300 секунд.
3. События должны быть упорядочены по времени.
4. Используй осмысленные id для машин/автобусов/пешеходов.
5. Возвращай ТОЛЬКО JSON, без markdown-обёртки.

Базы данных

Таблица roadrunner_scenarios

CREATE TABLE roadrunner_scenarios (
  id BIGSERIAL PRIMARY KEY,
  name TEXT NOT NULL DEFAULT '',
  description TEXT NOT NULL DEFAULT '',
  scenario_data JSONB NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  author TEXT NOT NULL DEFAULT 'system'
);

Таблица roadrunner_settings

CREATE TABLE roadrunner_settings (
  key TEXT PRIMARY KEY,
  settings JSONB NOT NULL
);

  "request": "Вечерний дождь на большой садовой, машины едут медленно, пешеходы с зонтами"

{
  "success": true,
  "scenario": { ... }

Генерация через AI-агент

AI-агент может использовать api/PROMPT.md как системный промпт для генерации сценариев. Пример запроса:

"Хочу добавить Санта Клауса на санях с оленями на Новый год"

→ AI генерирует сценарий:
{
  "id": "santa-claus-new-year",
  "name": "Санта Клаус на Новый год",
  "duration": 60,
  "events": [
    {"t": 0, "do": "change_time_of_day", "params": {"phase": "night"}},
    {"t": 1, "do": "start_snow", "params": {"intensity": 0.8}},
    {"t": 2, "do": "add_holiday_decor", "params": {"type": "snow"}},
    {"t": 5, "do": "add_vehicle", "params": {"type": "sleigh", "color": "red"}},
    {"t": 55, "do": "end"}
  ]
}
