# Шрифты и лицензии

Все веб-шрифты сайта хранятся локально в этом каталоге и раздаются с домена
сайта. Внешние запросы к Google Fonts не выполняются.

| Семейство  | Файлы                | Лицензия                  | Источник                                                                              |
| ---------- | -------------------- | ------------------------- | ------------------------------------------------------------------------------------- |
| Inter      | `inter/*.woff2`      | SIL Open Font License 1.1 | [Google Fonts / Inter](https://github.com/google/fonts/tree/main/ofl/inter)           |
| Roboto     | `roboto/*.woff2`     | Apache License 2.0        | [Google Fonts / Roboto](https://github.com/google/fonts/tree/main/apache/roboto)      |
| PT Sans    | `pt-sans/*.woff2`    | SIL Open Font License 1.1 | [Google Fonts / PT Sans](https://github.com/google/fonts/tree/main/ofl/ptsans)        |
| Montserrat | `montserrat/*.woff2` | SIL Open Font License 1.1 | [Google Fonts / Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat) |
| Manrope    | `manrope/*.woff2`    | SIL Open Font License 1.1 | [Google Fonts / Manrope](https://github.com/google/fonts/tree/main/ofl/manrope)       |

Полные тексты лицензий:

- `OFL-Inter.txt`, `OFL-PTSans.txt`, `OFL-Montserrat.txt`, `OFL-Manrope.txt` —
  SIL Open Font License 1.1.
- `LICENSE-Roboto.txt` — Apache License 2.0.
- `LICENSE-MaterialIcons.txt` — Apache License 2.0 (иконки Material Icons,
  поставляются пакетом `@quasar/extras`).

## Что разрешено

- Использование в коммерческом сайте и в документах компании.
- Встраивание в веб-страницы, PDF и другие материалы.
- Передача файлов шрифтов в составе проекта.

## Что нужно соблюдать

- Сохранять тексты лицензий и уведомления об авторских правах вместе с файлами
  шрифтов (этот каталог и является таким уведомлением).
- Не продавать шрифты отдельно от продукта.
- При изменении шрифта и его распространении соблюдать правила OFL о
  зарезервированных названиях и переименовании производных версий.
- Для Apache License 2.0 сохранять `LICENSE-Roboto.txt` и отмечать изменения,
  если файлы модифицировались.

Изображения на сайте — собственные материалы РА «Альбион» либо изображения,
свободные для коммерческого использования / используемые на основании
подтверждённых прав. Сторонние изображения не должны добавляться без проверки
лицензии.
