# UI-аудит и дорожная карта (22.10.2026)

> Аудит UI-компонентов: кнопки, фильтры, подборки, выделение, отображение.
> Учтены `albion-reports/site/ОТЧЕТ_АЛЬБИОН_САЙТ.md` (§15, §17, §18) и
> `albion-reports/tz/TZ_АЛЬБИОН_САЙТ.md` (§2.7, §3.3, §3.8).
>
> **Шкала:** P1 — ломает основной сценарий или показывает неверные данные;
> P2 — заметно мешает или включается при возврате кабинета; P3 — гигиена.
> P0 в UI-коде нет: P0 отчёта относятся к инфраструктуре и закрываются
> Этапами 0–1 ТЗ.

## 1. Принятые решения

| Вопрос | Решение |
|---|---|
| Личный кабинет | Убрать из активного UI, код и таблицы сохранить; вернуть флагом `ACCOUNT_UI_ENABLED` |
| Реквизиты | Не выводить; код сохранить, вернуть вместе с кабинетом |
| Портфель | `localStorage`, живёт до очистки браузера |
| Чат | `sessionStorage`; текст ходов — в `chat_turns`, виден в админке |
| Ссылки | Читаемая схема + компактный клиентский токен; серверные короткие — позже |
| QR | В мобильной версии; сейчас только генерация ссылки |
| Виртуализация списка | Не трогаем: до 2000 карточек, на десктопе просадок нет; мобильный замер позже |
| Картинки | Сначала исправить `sizes` и добавить уменьшенные варианты, затем WebP/AVIF по замеру |

## 3. Дорожная карта

| Этап | Срок | Работы | Критерий приёмки |
|---|---:|---|---|
| **UI-0. Подготовка** | 2 дня | Флаги и документация ЛК/реквизитов; спецификация URL; baseline-тесты; шаг 1 по картинкам | Сборка/тесты зелёные; решения зафиксированы в `doc/` |
| **UI-1. Каталог** | 5 дней | Точка/геокодер/race, `ready`-цикл, пересоздание карты, `flyTo`, балуны Яндекса; читаемый URL + дебаунс + legacy | Ссылка восстанавливает фильтры и режим; координаты не расходятся; нет ошибок в консоли |
| **UI-2. Портфель и шаринг** | 4 дня | Пустые позиции как норма (0 ₽, тест экспорта), undo при удалении, индекс `Map`; компактная ссылка + переключатель и тест-панель в админке | Пустая позиция в файлах/печати; ссылка и переключатель работают |
| **UI-3. Картинки и замеры** | 4–6 дней | Замер 100 картинок; `640w`, WebP; при выигрыше — AVIF; диффинг меток Яндекса, ленивые попапы, split `HomeSlider` | ≥20% байт при SSIM ≥0,98; решения по форматам зафиксированы |
| **UI-4. UX/a11y** | 5 дней | Loading/error/empty на главной, клавиатура, aria, `q-dialog`, соцссылки, сообщения вместо `console` | Чек-лист TZ 2.7 закрыт |
| **UI-5. Тесты и мобильный спайк** | 6–8 дней | Vitest на композаблы, e2e, CI; мобильный замер списка | Регрессия не возвращается; решение по мобильной производительности на цифрах |

После каждого этапа — отчёт, демо и пауза на уточнения.

## 4. Связь с ТЗ

- **TZ 0** (секреты) — раньше любых деплоев.
- **TZ 1.1–1.2** (сборка + Nginx) — после него UI-1 проверяется на production-сборке.
- **TZ 2.1** (cookie-сессии) — требует единого адаптера админ-запросов (UI-0).
- **TZ 3.1** (пагинация/bbox) — требует схемы URL из UI-1.
- **TZ 3.3** (дебаунс, виртуальный список, code splitting) — UI-1/UI-3; route-level splitting уже есть.
- **TZ 3.8** (a11y) — UI-4.

## 5. Что уже закрыто

- Route-level code splitting — все страницы в `router/routes.js` через `import()`.
- Loading/error/empty на контактах — `ContactsPage.vue`.

  (`portfolioExport.js`, `backend/services/portfolio_export.py`).
