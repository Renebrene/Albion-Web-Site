# Геокодинг адреса и точки

Тонкий серверный прокси к Yandex Geocoder/Geosuggest для поиска по адресу и
обратного геокодирования точки. Ключи не попадают в браузер.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `ALBION_YANDEX_GEOCODER_KEY` | серверный ключ Yandex Geocoder |
| `ALBION_YANDEX_SUGGEST_KEY` | серверный ключ Yandex Geosuggest |

Допускаются fallback-имена `YANDEX_API_KEY` и `YANDEX_SUGGEST_API_KEY`.
Ключ карты `VITE_YANDEX_MAPS_KEY` для геокодера не подходит.

## Эндпоинты

Все пути публичные (без админ-токена), но ограничены rate-limit:

- `POST /api/geo/geocode` — `{"query": "Ростов-на-Дону, Большая Садовая 1"}`
  → `{lat, lon, address, precision, source}`.
- `POST /api/geo/reverse` — `{"lat": 47.2, "lon": 39.7}`
  → `{address, district, source}`; без ключа возвращает `null`-поля.
- `POST /api/geo/suggest` — `{"query": "Большая Садовая", "limit": 8}`
  → `{suggestions: [{id, title, subtitle, display_name, query}], source}`.
- `GET /api/geo/status` — только boolean-флаги наличия ключей.

Лимиты по умолчанию: geocode/reverse — 30/мин с IP, suggest — 120/мин.
Переопределяются `ALBION_RATE_GEOCODE_PER_MIN`, `ALBION_RATE_REVERSE_PER_MIN`,
`ALBION_RATE_SUGGEST_PER_MIN`.

## Регион и ошибки

Подсказки ранжируются вокруг центра Ростова-на-Дону (`ll`/`spn`), поэтому
«Курчатова» находит ростовскую улицу, а не Волгодонск. Если в запросе к
геокодеру не указан Ростов-на-Дону, город добавляется в текст запроса;
явно указанный другой город (`Ленина, Таганрог`) имеет приоритет. Жёсткий
bbox области не используется. Результат геокодера проверяется по компоненту
`province/area = Ростовская область`; адрес вне региона → `404`. Ошибки
провайдера:

| HTTP | Причина |
|---:|---|
| 404 | адрес не найден в Ростовской области |
| 429 | превышен лимит Яндекса |
| 503 | не настроен ключ / нет доступа |
| 504 | таймаут Яндекса |
| 502 | некорректный ответ или сеть |

Ответы кэшируются в процессе на 5 минут (до 500 записей).

## Frontend

`frontend/src/services/geoApi.js` вызывает `/api/geo/*`.
В режиме «Поиск по точке и адресу» верхняя строка поиска работает через
геокодер:

- по умолчанию выбран режим «Адрес»; ввод с debounce 300 мс показывает
  подсказки прямо под строкой;
- выбор подсказки или Enter выполняет геокодирование;
- успешный результат фиксирует точку, заполняет адрес и центрирует карту;
- переключатель «Координаты» принимает широту и долготу через запятую;
- при фиксации координат выполняется обратный геокодер и заполняет адрес,
  если поле пустое;
- ошибки показываются под поисковой строкой.

В режимах «Интерактивная карта» и «Список» строка поиска не обращается к
геокодеру: это фильтр по базе — город, улица, номер или формат. Подсказки
там не запрашиваются, а ранее зафиксированная точка при вводе снимается,
чтобы фильтр работал по всему каталогу.

## Приватность

Адресные строки и координаты отправляются в Yandex. Ключи должны быть
ограничены по продукту/квоте; `ALBION_YANDEX_GEOCODER_KEY` хранится только на
сервере.
