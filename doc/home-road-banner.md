# Слайд «Светофорные объекты» на главной

Слайд главной страницы с 3D-баннером «живая дорога». Заголовок и текст
редактируются в админке как у обычного слайда, а сам баннер — это
самостоятельный HTML-документ, который администратор загружает файлом или
вставляет в поле кода. Код хранится в БД (`home_slides.code`) и не требует
пересборки фронтенда для обновления.

## Где это в интерфейсе

- Слайд стоит **сразу перед новостным** (тип `road-banner`).
- Заголовок: «Светофорные объекты».
- Баннер занимает нижнюю часть визуальной области слайда, на всю ширину;
  поверх него работает листание слайдов колесом/свайпом
  (`pointer-events: none` у iframe).

## Админка

**Администрация → Баннер-дорога** (отдельная закладка, `/administration/banner`):

- Поле **HTML-кода** баннера; код хранится в `home_slides.code` и
  сохраняется в БД между сессиями.
- Панель **«Настройки из кода»** — читает блок
  `<script type="application/json" id="banner-settings">` и показывает все
  найденные параметры ползунками/полями/переключателями. Изменение поля
  сразу переписывает значение в блоке кода (код в редакторе обновляется).
- Ручная правка кода тоже подхватывается: через ~0,35 с настройки
  перечитываются из блока.
- **«Сохранить»** — `PATCH /api/admin/home/slides/{id}` с новым кодом.
- **«Запустить»** — перезагружает предпросмотр (sandbox-iframe с последним
  сохранённым кодом).
- **«Заменить файлом»** — загрузить `.html/.htm/.txt` (до 512 КБ).
- **«Скачать код»** и **«Сбросить к стандартному»** — выгрузка и возврат
  шаблона из `backend/templates/road_banner.html`.

Со слайда на главной в блоке «Баннер-дорога» есть кнопка, ведущая в эту
закладку; заголовок и текст слайда по-прежнему редактируются в
«Главная страница».

### Формат настроек

В коде должен быть JSON-блок:

```html
<script type="application/json" id="banner-settings">
{
  "tilt": { "value": 32, "label": "Наклон камеры", "min": 5, "max": 85, "step": 1, "unit": "°" },
  "buses": { "value": true, "label": "Автобусы", "type": "boolean" },
  "quality": { "value": "eco", "label": "Качество", "type": "select",
               "options": [{"value":"eco","label":"Эко"}] }
}
</script>
```

- число + `min`/`max` → ползунок;
- число без границ → числовое поле;
- `true/false` → переключатель;
- `type: "select"` + `options` → выпадающий список;
- остальные значения → текстовое поле.

Баннер читает этот блок при запуске и применяет значения. Если заменить код
на свой HTML, блок можно оставить или убрать — тогда панель настроек
покажет подсказку, а код продолжит работать сам по себе.

## Как это работает

- Публичный список `GET /api/home` отдаёт только флаг `has_code`
  (сам код не тащит — это десятки килобайт).
- Когда слайд активен, `RoadBannerSlide.vue` монтирует
  `<iframe src="/api/home/slides/{id}/code" sandbox="allow-scripts">`.
- `GET /api/home/slides/{id}/code` отдаёт документ с `text/html` и отдельной
  CSP (`BANNER_CODE_CSP` в `backend/services/home_service.py`). Вне iframe
  код не вставляется.
- `GET /api/admin/home/slides/{id}/code` — то же для админского
  предпросмотра, работает и для скрытого слайда.
- Iframe снимается с активного слайда при уходе — WebGL-сцена не крутится
  в фоне.

### Поведение сцены

Все параметры ниже — значения по умолчанию из блока `#banner-settings`;
их можно менять в закладке «Баннер-дорога» без правки остального кода.

- **Качество** — `eco` (pixel ratio 1).
- **День/ночь** — цикл 48 секунд: день → закат → ночь → рассвет;
  свет, окна, фонари и подсветка щита меняются плавно.
- **Трафик** — плотность случайно меняется каждые 5–12 секунд (0.55×–1.9×),
  интервалы спавна машин и автобусов пересчитываются от неё.
- **Скорость** — плавная «волна» 0.65×–1.35× с периодом ~20 секунд
  (машины и автобусы).
- **Количество** — целевое число машин (6–13) и ожидающих пешеходов (1–5)
  меняется случайно каждые 6–14 секунд.
- **Камера** — наклон/поворот/масштаб из настроек; по умолчанию ракурс
  подобран так, чтобы в кадр целиком попадал рекламный щит «АЛЬБИОН».
- `prefers-reduced-motion` — сцена ставится на паузу, день/ночь не крутится.

### Безопасность

Код выполняет администратор, но всё равно изолирован:

- `sandbox="allow-scripts"` **без** `allow-same-origin` — у документа
  непрозрачный origin, нет доступа к cookie, `localStorage` и API сайта;
- CSP документа: `default-src 'none'`, разрешены только inline-скрипты,
  стили и `https://cdn.jsdelivr.net` (three.js);
- `form-action 'none'`, `base-uri 'none'`, `frame-ancestors 'self'`.

В nginx (см. `deploy/nginx.conf.example`) для этого пути заведён отдельный
`location`, потому что глобальный CSP сайта запрещает inline-скрипты и CDN.
При добавлении новых внешних хостов в код баннера правьте **оба** места:
`BANNER_CODE_CSP` и этот `location`.

## Миграция

```bash
.venv/bin/python -m backend.migrations.migrate_home_banner_code
```

Скрипт идемпотентен:

- добавляет `home_slides.code`, если колонки нет;
- если слайда `kind='road-banner'` ещё нет — вставляет его перед первым
  слайдом `kind='news'` и записывает стартовый код из шаблона.

После миграции перезапустите бэкенд (новый роут `/api/home/slides/{id}/code`).

## Проверка

1. `GET /api/home` — в слайде `road-banner` есть `"has_code": true`,
   ключа `code` нет.
2. `GET /api/home/slides/{id}/code` — `200 text/html`, в заголовке
   `Content-Security-Policy` есть `sandbox allow-scripts`.
3. Главная → третий слайд: заголовок, текст и анимированная дорога внизу.
4. Админка → «Баннер-дорога»: изменить настройку ползунком — блок JSON в
   коде обновился; сохранить → обновить главную: баннер обновился.
