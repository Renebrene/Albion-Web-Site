# Известные грабли

Симптом → причина → что делать. Дополняйте по мере появления новых.

## Карта

**Пропали маркеры / карта пустая.**
Причина: упал бэкенд (dev-прокси отдаёт 502) или ошибка в `/api/constructions`.
Проверить: `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8000/api/home`.
Перезапустить бэкенд.

**Карта на Leaflet, хотя в настройках выбран Яндекс.**
Причина: загрузчик Yandex API отказался (нет ключа, неверный ключ, домен не
разрешён) — `MapView` молча откатывается на Leaflet.
Смотреть консоль: `не задан ключ API (VITE_YANDEX_MAPS_KEY)` или
`не удалось загрузить скрипт api-maps.yandex.ru`.

**Ключ Яндекса не подхватывается из `.env.local`.**
Причина: Quasar отдаёт в клиентский бандл только переменные с префиксом `QCLI_`
или `VITE_`; префикс задаётся в `frontend/quasar.config.js` (`build.env.clientPrefix`).
Значение вшивается в сборку — после правки `.env.local` **перезапустить dev или
пересобрать**. Проверить: открыть `/src/config/mapConfig.js` в dev — ключ должен
быть в `import.meta.env`.

**Кнопка «Карта» в попапе/списке открывает фото, а не карту (или наоборот).**
Смотри `data-photo-*` в разметке `popupContent.js` и делегированные обработчики
в `AdvertisingPage.vue`.

## Экспорт портфеля

**Экспорт doc/odt/rtf/pdf падает или без кириллицы.**
Причина: нет LibreOffice (`soffice`) или шрифтов `DejaVu`/`Liberation`.
Проверить: `which soffice`; шрифты ищутся в
`/usr/share/fonts/truetype/dejavu/` и `.../liberation/` (`find_cyrillic_fonts`).
Установить: `apt install libreoffice-writer libreoffice-calc fonts-dejavu fonts-liberation`.

**Несколько экспортов подряд вешают сервер.**
Причина: каждый экспорт запускает процесс `soffice`; при нескольких воркерах это
пик по памяти. Ограничивать параллелизм или число воркеров.

## База данных

**Изменения «не сохраняются» / нужен ли `commit()`?**
`with get_connection() as conn` в psycopg3 **коммитит при выходе** без исключения.
Явный `commit()` обычно не нужен; при ошибке — откат.

**Миграция падает при повторном запуске.**
Миграции в `backend/migrations/` должны быть идемпотентными (`IF NOT EXISTS`,
проверки существования). Пример идемпотентной — `migrate_contacts_v2.ensure_columns`.

**Дубликаты авто-бекапов при нескольких воркерах.**
Причина: планировщик стартует в каждом процессе. Защита — advisory-lock
(`pg_try_advisory_lock`) в `site_backup_service.ensure_weekly_backup`.
Покрыто тестом `backend/tests/test_site_backup_scheduler.py`.

## Запросы к API

**Логин/восстановление отдаёт 429.**
Причина: сработал in-memory rate-limit (`_RATE_RULES` в `backend/main.py`).
Подождать; на прод — ограничивать на уровне nginx.

**Загрузка файла отдаёт 413.**
Причина: превышен лимит (`MAX_REQUEST_BYTES` / лимит по типу файла). Проверить
размер и тип в `media_service` / `upload_limits`.

**CMS-ссылка «не работает» / отклоняется.**
Причина: серверный санитайз (`cms_url.clean_cms_url`) отбрасывает `javascript:`,
`data:`, `//host` и т.п. Разрешены относительные пути, `http(s)`, `mailto:`, `tel:`.

**Новый внешний ресурс блокируется на странице.**
Причина: CSP в `frontend/index.html` (и в `deploy/nginx.conf.example`). Добавить
хост в `img-src`/`connect-src`/`script-src` в **оба** места.

## Фронтенд

**Правки в `.env.local` не видны.**
Vite читает env на старте → перезапустить dev-сервер. В прод — пересобрать.

**`oxfmt` сломал `.vue`-шаблон.**
Крупный автоформат может испортить многострочную разметку (известный случай —
`@click="a; b"`). Правьте точечно; при массовом форматировании — проверять сборку.

**Сборка проходит, но страница пустая.**
Смотреть консоль браузера; частая причина — ошибка импорта чанка или недоступный
`/api`. Проверить `bun run build` и поднятый бэкенд.

## Процессы/окружение

**`pkill -f "quasar dev"` убивает и собственную команду.**
Шаблон совпадает с самой командой. Убивать по pid
(`pgrep -f node_modules/.bin/quasar`), а не по строке с тем же текстом.

**Бэкенд не видит `.env`.**
`data_service` вызывает `load_env_file(PROJECT_DIR/".env")` при импорте — файл
должен лежать в корне проекта.
