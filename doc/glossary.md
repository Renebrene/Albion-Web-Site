# Глоссарий

Термины проекта — как они понимаются в коде. Источники: `frontend/src/utils/constructionGroups.js`
(терминология и группировка), `frontend/src/utils/availability.js` (статусы).

## Объекты рекламы

- **Конструкция** — рекламная конструкция на местности. Определяется парой
  **адрес + номер**: один объект, одна координата. В базе ей соответствует запись
  в таблице конструкций.
- **Сторона** — буквенная сторона конструкции: `A`, `B`, `C`; на разделительной
  полосе — `A1`, `A2`. Показывается как в базе, без нормализации регистра.
- **Поверхность** — конкретная рекламная плоскость **на стороне**, с индексом в
  скобках: `A(1)`, `A(2)`, `A1(2)`. У поверхности есть свой `id` (для портфеля).
- **Динамическая сторона** — сторона с **несколькими поверхностями** (например,
  призматрон: `A(1)+A(2)+A(3)`). **Статическая сторона** — одна поверхность.
  Логика распознавания — `isDynamicSide()` в `constructionGroups.js`.
- **Формат (тип)** — `type` конструкции: щит, пилон, скроллер, пиллар,
  призматрон, видеоэкран и т. п.
- **Семейство (`family`)** — группа форматов, задающая максимум блоков в попапе:
  `pillar` → до 3, остальные → 2 (`familyOf`, `maxBlocksFor`).
- **Группа (`groupSides`)** — поверхности, сгруппированные по **формату + стороне**;
  `kind`: `video` (видеоэкран, всегда динамический), `dynamic` (несколько
  поверхностей), `static` (одна).
- **Точка (`groupByPoint`)** — одна карточка/маркер на карте. Ключ точки —
  **координата** (округление до 5 знаков); без координат — по адресу.
  Видеоэкран — исключение: каждый экран отдельная точка (не сливается по
  координате).
- **Дедупликация сторон (`dedupeSides`)** — одна и та же буква у **разных
  форматов** — это разные блоки, поэтому ключ включает и формат.

## Доступность

- **Месяцы** — набор берётся **из данных** (реактивный `MONTHS` в
  `constructionGroups.js`, наполняется через `setMonthsFromItems` из
  `/api/constructions`). Раньше был фиксированным списком.
- **Статус месяца** (`getAvailabilityState`) — одно из:
  - `free` — свободно (в т. ч. когда данных нет);
  - `reserve` — резерв/требует уточнения (`резерв`, `утверж`);
  - `busy` — занято/продано (`продан`, `занят`, `100%`).
- **Цвет точки на карте** — сводка по сторонам за выбранные месяцы:
  «свободно» / «смешанный» / «занято», либо двухцветный режим
  (зелёный, если есть хоть одна свободная поверхность). См. `config/mapColors.js`
  и `doc/map.md`.
- **Режим доступности (`availableMode`)** — настройка отображения доступности
  (трёх-/двухцветный) и количества динамических поверхностей (`dynCount`).

## Портфель

- **Портфель** — «корзина» выбранных **сторон** с месяцами. Состояние —
  синглтон `usePortfolio`, хранится в `localStorage` (`albion_portfolio`) и
  синхронизируется с личным кабинетом.
- **Позиция портфеля** — **сторона** + выбранные месяцы (с ценой/статусом).
  У стороны может быть несколько поверхностей (призматрон A(1)…A(3)), и
  свободная в каждом месяце — своя, поэтому поверхность запоминается **у
  месяца** (`months[месяц].surfaceId`): позиция остаётся одна на сторону,
  а цена и статус месяца берутся у той поверхности, которая его отдаёт.
  Свободность месяца считается по стороне целиком — «свободно», если
  свободна хотя бы одна её поверхность (как на карточке и в попапе).
  Логика — `toggleSideMonth` / `isSideMonthLocked` в `composables/usePortfolio.js`.
- **Режим выбора (`pf-mode`)** — состояние секции попапа/карточки, в котором
  доступен выбор месяцев (включается кнопкой «Портфель»).
- **Экспорт** — выгрузка портфеля в файл; см. `doc/portfolio-export.md`.

## Сайт и контент

- **Слайд** — вертикальный экран на главной (`HomeSlider.vue`): типы `hero`,
  `news`, `geo`, `form`, `text`.
- **Кадр** — отдельный экран горизонтальной карусели внутри hero-слайда.
- **Локация** — город или район в geo-слайде; у локации бывают описание и
  обложка.
- **Достопримечательность** — карточка в geo-слайде с описанием и галереей фото
  (каждое фото имеет источник/атрибуцию).
- **CMS** — управляемый из админки контент: новости, страницы, контакты, меню,
  о компании.

## Импорт и медиа

- **Импорт** — загрузка прайса (Excel) → JSON → staging → PostgreSQL.
- **Архив импорта** — сохранённый слепок исходных данных и медиа (для отката);
  см. `doc/import-pipeline.md`.
- **Медиа** — файлы конструкций (фото, карта-схема) в `storage/`; в БД — метаданные.
- **Атрибуция** — `source_name` / `source_url` / `license` для фото, взятых из
  открытых источников.
