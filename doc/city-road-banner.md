# CityRoadBanner — анимированный 3D-баннер «Городская дорога»

Декоративный low-poly баннер для шапки страницы: двухсторонняя дорога,
два перекрёстка с зебрами и синхронными светофорами (фазы сдвинуты),
пешеходы в окне all-red, поток машин из объектного пула. Вся графика
генерируется кодом (Three.js, точечные импорты для tree-shaking) —
никаких ассетов.

## Подключение

Единственная новая зависимость — `three` (уже в `frontend/package.json`):

```bash
cd frontend && bun add three
```

Использование в любом месте (например, в самом верху `q-page`):

```vue
<script setup>
import CityRoadBanner from '@/components/common/CityRoadBanner.vue'
</script>

<template>
  <q-page>
    <CityRoadBanner :height="280" :traffic-density="1" :speed-factor="1" />
    <!-- остальной контент страницы -->
  </q-page>
</template>
```

Баннер занимает всю ширину контейнера, `pointer-events: none` — не
перехватывает wheel/touch, скролл страницы работает поверх него.

## Props

| Prop | Тип | Default | Описание |
|---|---|---|---|
| `height` | number | `null` | Высота в px; `null` — адаптивная (280 десктоп / 180 < 640px) |
| `trafficDensity` | number | `1` | Плотность трафика (0.3–2.0), множитель интервалов спавна |
| `speedFactor` | number | `1` | Множитель скорости машин, разгона и торможения |
| `paused` | boolean | `false` | Внешняя пауза (рендер останавливается) |
| `greenDuration` | number | `7` | Зелёная фаза светофора, с |
| `yellowDuration` | number | `2.4` | Жёлтая фаза, с |
| `redDuration` | number | `12` | Минимальная красная фаза, с (реальная длиннее: включает all-red для пешеходов) |

## Events

- `@ready` — сцена инициализирована
- `@error` — ошибка инициализации (в этом случае показан статичный SVG-фолбэк в той же палитре)

Страница `/city-road-banner-demo` (`frontend/src/pages/CityRoadBannerDemoPage.vue`):

## Устройство (вкратце)

- **Светофоры** — конечный автомат на цикле `зелёная → жёлтая → all-red →
  зелёная встречного → жёлтая → all-red`; встречное направление сдвинуто на
  половину цикла, второй перекрёсток — ещё на половину (зелёная волна чередуется).
  Жёлтая фаза с commit-zone: машина успевает — проезжает, нет — тормозит до
  стоп-линии (бампер не заезжает на зебру).
- **Машины** — объектный пул (14 штук, жёсткий предел), геометрии разделяются;
  кинематика: разгон, тормозной профиль `sqrt(2·a·d)` до стоп-линии,
  дистанция до впереди идущего; спавн/деспавн за краем видимости.
- **Производительность** — один RAF на компонент, merge статики в несколько
  мешей (всего &lt; 150 draw calls), fake-тени эллипсами (shadow map не
  используется), `pixelRatio ≤ 2`, все расчёты на дельта-времени с clamp
  (одинаково на 30/60/144 fps), ноль аллокаций в кадре.
- **Паузы** — IntersectionObserver (вне вьюпорта) + `visibilitychange`
  (скрытая вкладка) + prop `paused`; `prefers-reduced-motion` — один
  статичный кадр.
- **Resize** — ResizeObserver: размер canvas, frustum камеры и границы
  спавна обновляются без пересоздания сцены; на узком экране камера
  «отъезжывает», чтобы оба перекрёстка остались в кадре.
- **Очистка** — на unmount: отмена RAF, отключение всех наблюдателей и
  слушателей, dispose геометрий/материалов/текстур, `forceContextLoss` +
  `renderer.dispose()`.
- **Фолбэк** — без WebGL (или при ошибке инициализации) — статичный SVG
  в той же палитре, без ошибок в консоли.

Инициализация Three.js — только в `onMounted` (клиент), SSR-безопасно.
