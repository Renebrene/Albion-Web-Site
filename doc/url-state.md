# Состояние фильтров в URL и обмен ссылками

> **Статус:** спецификация; реализация — этапы UI-1/UI-2 дорожной карты.
> **Связанные документы:** [`ui-audit-2026-10-22.md`](ui-audit-2026-10-22.md),
> [`frontend.md`](frontend.md), [`map.md`](map.md).

## 1. Задача

Пользователь настраивает каталог (город, формат, месяцы, поиск, режим —
карта/список/точка) и хочет передать это коллеге ссылкой. При открытии
ссылки сайт сам восстанавливает фильтры и нужный экран.

Требования:

- ссылка открывается в браузере без установки приложения;
- состояние восстанавливается после перезагрузки и из чужого браузера;
- старые ссылки продолжают работать;
- ссылка не содержит персональных данных;
- при переполнении — понятная ошибка, а не молчаливая обрезка.

## 1.1. Что уже реализовано (UI-1)

В `AdvertisingPage.vue` работает читаемая схема и обратная запись:

- параметры: `city`, `type` (мультизначения), `months`, `monthLogic`,
  `address`, `mode`, `lat`, `lng`, `radius`, `addr`;
- гидратация один раз после загрузки справочников, затем Back/Forward
  применяет URL повторно;
- запись фильтров — с debounce 300 мс и сравнением канонического query;
- старый формат `?city=...&type=...&address=...` поддерживается;
- `?chat=1` и посторонние параметры (utm и т.п.) сохраняются.

Пока используются значения справочника (названия городов/форматов и
имена месяцев из данных). Переход на `YYYY-MM` и латинские коды —
следующий шаг, когда появятся стабильные ID.

Компактный токен `?s=v1-…` реализован (`frontend/src/utils/urlState.js`):
UTF-8 JSON с короткими ключами → Base64Url или Base32. Разбор всегда
принимает и токен, и читаемые параметры. Режим генерации переключается
в админке: **Настройки → Ссылки и QR** (`url_state_mode`), там же —
панель проверки кодирования. Кнопка «Поделиться» в каталоге копирует
ссылку в выбранном формате. Серверные короткие ссылки `/s/<code>` —
следующий этап (UI-5), если понадобятся.

## 2. Три режима

| Режим | Пример | Кто разбирает | Когда использовать |
|---|---|---|---|
| `readable` | `?mode=list&city=1,4&type=shield,pillar&months=2026-10,2026-11&logic=AND` | браузер | основной режим, отладка, аналитика |
| `compact` | `?s=V1-7QK3M9X2...` | браузер (JS) | короткая ссылка, будущий QR |
| `short` | `/s/Ab3xK9` | сервер | очень большие состояния, статистика переходов |

Во всех режимах **разбор принимает все форматы** и старый формат
(`?city=Ростов-на-Дону&type=Щит&address=...`). Режим влияет только на то,
какую ссылку генерирует кнопка «Поделиться».

### 2.1. Читаемый режим

```
/vozmozhnosti
  ?v=1
  &mode=list
  &city=1,4
  &type=shield,pillar
  &months=2026-10,2026-11
  &logic=AND
  &q=Ленина
```

Правила:

- `v` — версия схемы (сейчас `1`);
- `mode` — `map` | `list` | `point`;
- `city` — стабильные числовые ID или латинские коды через запятую;
  отсутствие параметра = все города;
- `type` — коды форматов; отсутствие = все форматы;
- `months` — `YYYY-MM` через запятую; отсутствие = без фильтра по месяцам;
- `logic` — `OR` (по умолчанию) | `AND`;
- `q` — поисковая строка (до 100 символов);
- для `mode=point`: `lat`, `lng` (6 знаков), `radius` (метры);
- для `mode=map`: опционально `zoom`, `lat`, `lng` (центр карты).

Кириллицу в URL не кладём: браузер раздувает её percent-encoding в три
раза. Коды городов/форматов — латиница из стабильного справочника.

### 2.2. Компактный режим

Состояние упаковывается в бинарный формат, затем кодируется в
`Base64Url` (по умолчанию) или `Base32` (для ручной диктовки).

Раскладка (предложение; версия 1):

| Поле | Биты | Комментарий |
|---|---:|---|
| версия | 4 | `1` |
| режим | 2 | map/list/point |
| флаги | 2 | logic, наличие точки |
| города | 1 + 32 | count + битовая маска по справочнику |
| форматы | 8 | битовая маска |
| месяцы | 12 | битовая маска для одного года |
| год | 7 | смещение от 2020 |
| точка | 65 | lat/lng (×1e5) + радиус |
| запрос | 8 + N | длина + UTF-8 |
| CRC | 8 | контроль целостности |

Для типичного состояния (2 города, 2 формата, 2 месяца) — 6–10 байт,
то есть 8–14 символов `Base64Url`. Для «все города/все форматы» маски
заполнены единицами, длина не растёт.

Если выбран `Base32`, используем Crockford-алфавит без `I`, `L`, `O`,
`U` — его удобно диктовать, но он длиннее `Base64Url` примерно на 20%.

### 2.3. Серверный режим

```
POST /api/share  { state: {...} }  ->  { code: "Ab3xK9", url: "/s/Ab3xK9" }
GET  /s/Ab3xK9                     ->  302 /vozmozhnosti?s=...
```

- таблица `shared_states(id, code, payload, created_at, expires_at)`;
- TTL по умолчанию 90 дней, очистка фоновой задачей;
- rate-limit на создание;
- включается флагом `url_state_short_enabled` (по умолчанию выключен).

Серверный режим не является «шифрованием»: он просто хранит состояние
и отдаёт его по короткому коду. Для фильтров он не обязателен; нужен,
если появится явный список карточек (тысячи ID), который не влезает
в URL.

### 2.4. Ссылка на портфель (`?pf=…`)

Отдельный параметр `pf` переносит **только портфель**: позиции (стороны) и
выбранные месяцы. Фильтры, режим и точка остаются в `?s=` / `?city=…` —
получателю важен тот же набор позиций, а не чужая выдача.

```
/vozmozhnosti?pf=v1-eyJ2IjoxLCJwIjpbWzI4MjIwLFsxMF1dXX0
```

Раскладка полезной нагрузки (JSON → Base64Url/Base32, алфавит — из
`url_state_token_format`, как у `?s=`):

| Поле | Значение |
|---|---|
| `v` | версия схемы, сейчас `1` |
| `t` | название портфеля (до 120 символов), необязательно |
| `p` | список `[surfaceId, [месяцы]]`; месяцы — индексами 1–12 по календарю |

Реализация — `frontend/src/utils/portfolioLink.js` (кодек) и
`PortfolioPanel.vue` → «Ссылка на портфель». Разбор — на странице каталога:
позиции собираются из загруженного `/api/constructions` **после** загрузки
и **до** `syncWithConstructions`, чтобы цены и статусы дозаполнились сразу.
Параметр из адреса убирается после применения (`router.replace`), иначе он
пережил бы перезагрузку и сработал повторно.

Если у получателя уже есть свой портфель и он отличается — показывается
вопрос: «ОК» заменяет портфель целиком, «Отмена» дополняет текущий.
Позиции, которых больше нет в каталоге, не восстанавливаются (о числе
недоступных сообщается). Битый или слишком большой токен — понятное
сообщение, страница не падает.

## 3. Пределы и валидация

| Параметр | Предел |
|---|---:|
| Длина читаемой ссылки | 1500 символов |
| Длина компактного токена `s` | 512 символов |
| Длина токена портфеля `pf` | 900 символов |
| Длина серверного кода | 8–12 символов |
| Поисковая строка `q` | 100 символов |
| Количество городов/форматов | по справочнику |
| Месяцы | 12 на год, до 2 лет |

При разборе:

- неизвестные параметры игнорируются;
- неизвестный `v` — ссылка не применяется, показывается сообщение;
- неверные коды городов/форматов отбрасываются, остальные применяются;
- битый CRC/токен — сообщение «Ссылка повреждена», без падения страницы;
- превышение лимита — сообщение, генерация короткой ссылки не выполняется.

## 4. Настройки в админке

В `SETTINGS_SCHEMA` добавляется группа `links`:

| Ключ | Тип | По умолчанию | Назначение |
|---|---|---|---|
| `url_state_mode` | select | `readable` | формат генерируемой ссылки |
| `url_state_token_format` | select | `base64url` | `base64url` или `base32` |
| `url_state_compression` | select | `deflate` | сжатие перед кодированием |
| `url_state_short_enabled` | toggle | `false` | серверные короткие ссылки |

Рядом — панель «Проверка ссылок»: выбрать фильтры/режим, получить
ссылку, её длину, декодированное состояние и ошибки. QR-код появится
позже вместе с мобильной версией; он кодирует уже готовую ссылку.

## 5. Интеграция во фронтенд

- `frontend/src/utils/urlState.js` — `encodeUrlState(mode, state)` и
  `decodeUrlState(query)`; чистые функции, покрываются unit-тестами.
- `frontend/src/composables/useUrlState.js` — связывает фильтры,
  `workspaceMode`, точку и роутер; дебаунс 300–500 мс.
- `AdvertisingPage.vue` — гидратация один раз при входе; `router.replace`
  только при реальном изменении; не сбрасывать скролл на каждый символ.
- `MapSearch.vue` — если в поле поиска вставлена ссылка или токен,
  применить состояние вместо текстового поиска.
- `PortfolioPanel`/тулбар — кнопка «Поделиться» (реализована в тулбаре каталога);
  в панели портфеля — «Ссылка на портфель» `?pf=…` (см. §2.4). QR — позже.

## 6. Тесты

- round-trip: state → encode → decode → state для всех режимов;
- кросс-режим: читаемая ссылка декодируется при `compact` и наоборот;
- legacy: старые `city`/`type`/`address`;
- битые токены, неверный CRC, неизвестная версия;
- предельные состояния: все города/форматы/месяцы, длинный `q`;
- e2e: открыть ссылку → проверить фильтры и режим.

## 7. Порядок внедрения

1. Читаемая схема + legacy + дебаунс (2 дня).
2. Компактный токен + переключатель и тест-панель в админке (2 дня).
3. Серверные короткие ссылки (2–3 дня, по необходимости).
4. QR в мобильной версии (отдельная задача).
