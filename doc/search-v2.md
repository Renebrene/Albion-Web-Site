# Поиск 2.0

Версия 2 работает рядом с прежним поиском и не меняет контракт `/api/search`.
Она убирает SQL с горячего пути, исправляет семантику типов/размеров/локаций и
добавляет нормализованный каталог в памяти процесса.

## Что было исправлено

| Проблема | Было | Стало |
|---|---|---|
| N+1 при маппинге | 2 SQL-соединения на каждую поверхность, «статики 3x6» — 31 с | `map_many`: overrides и медиа загружаются один раз; 0.3–0.4 с на v1 |
| Engine на каждый `/api/search` | новый SQLAlchemy Engine на запрос | singleton bridge + пул соединений |
| Синоним «скроллер» | маппился в несуществующий «Сити-борд» → 0 | `TypeResolver` находит реальный тип «Скроллер» |
| Размеры | строка `LIKE`; `1,2 X 1,8` и `1.8x1.2` не совпадали | числовые размеры с допуском, порядок сторон не важен |
| Город + район | OR, «Ростов + Октябрьский» → весь Ростов | strict: AND; район ищется только в city/district |
| `_primary_month` | минимальный месяц года | первый явно запрошенный месяц |
| Год | литерал 2026 | `ALBION_SEARCH_DEFAULT_YEAR` → max(year) из БД → текущий год |

## Эндпоинт

```http
POST /api/search/v2
Content-Type: application/json

{
  "media_type": "скроллер",
  "city": "Ростов-на-Дону",
  "size": "3x6",
  "month": 11,
  "location_mode": "strict",
  "explain": false
}
```

Ответ:

```json
{
  "count": 20,
  "total": 162,
  "results": [ ... тот же SearchResult, что у v1 ... ],
  "meta": {
    "version": "v2",
    "catalog_version": "...",
    "total": 162,
    "took_ms": 3.1,
    "resolved": {"city": "...", "media_type": "Скроллер", "size": {"major": 6, "minor": 3}},
    "warnings": []
  }
}
```

`total` считается до применения `limit`; `count` — длина отданного списка.

`location_mode=relaxed` делегирует в v1 и полезен для сравнения поведения.

## Каталог

- `backend/search/catalog.py` — снимок ~1500 поверхностей в памяти.
- `backend/search/catalog_loader.py` — один снимок: поверхности + overrides +
  медиа + availability; адреса разбираются при сборке, не на каждый запрос.
- Инвалидация — по `tmp/.data_cache_stamp` (его обновляют импорт и правки
  медиа/полей) и TTL `ALBION_SEARCH_CATALOG_TTL` (60 с).
- Диагностика: `GET /api/admin/search/catalog`, принудительная пересборка:
  `POST /api/admin/search/catalog/reload`.

После прогрева v2 не выполняет SQL на поиск.

## Умный чат

`ALBION_CHAT_SEARCH_VERSION=2` переключает чат на v2 (по умолчанию остаётся 1).
`ALBION_CHAT_SEARCH_VERSION=1` сохраняет прежний bridge.

## Ограничения

- Строгая локация использует только поля `city`/`district`. В текущих данных
  районы Ростова не размечены, поэтому «Ростов + Октябрьский район» даёт 0 и
  warning — это честнее, чем возвращать весь город.
- Rate-limit поиска/чата процесс-локальный: при нескольких uvicorn-воркерах
  нужен дополнительный `limit_req` в nginx.
- Импортёр по-прежнему пишет год кампании из `ALBION_IMPORT_YEAR`; поиск берёт
  максимальный год из availability.
