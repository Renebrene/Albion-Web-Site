АЛЬБИОН — современное демо с Яндекс Картами

Карта переведена на Yandex Maps JavaScript API v3.
В демо используется API-ключ, предоставленный владельцем проекта.

Важно:
- Для работы карты необходим интернет.
- Для JavaScript API v3 ключ должен иметь настроенное ограничение по HTTP Referer.
- Для локальной проверки рекомендуется запускать демо через локальный HTTP-сервер, например:
  python -m http.server 8000
  затем открыть http://localhost:8000/
- Перед публикацией на домене необходимо добавить домен в разрешённые Referer в кабинете разработчика Яндекс Карт.

Функции:
- 1569 рекламных конструкций из выгрузки;
- Яндекс Карты;
- маркеры по координатам;
- карточка объекта по клику;
- поиск;
- фильтры И + И;
- карта / список;
- центрирование и сброс фильтров.
