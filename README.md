# АЛЬБИОН.САЙТ

Сайт рекламной сети «Альбион» (Ростов-на-Дону): публичная витрина рекламных
конструкций, интерактивная карта, подборка (портфель), умный чат и
админ-панель для управления контентом и каталогом.

## Возможности

- Каталог конструкций на карте и списком: адреса, стороны, фото, цены,
  доступность по месяцам.
- Умная строка поиска: подсказки адресов, транслитерация, исправление
  опечаток, ограничение геокодера Ростовской областью.
- Подборка с месяцами, суммой, экспортом в документы и ссылкой для клиента.
- Умный чат: разбор запросов на естественном языке, результаты карточками,
  добавление свободных месяцев в подборку.
- Админ-панель: контент, каталог, медиа, импорт Excel, резервные копии,
  статистика, настройки и словари синонимов для чата.
- Редактируемые словари синонимов форматов, городов и ключевых слов.

## Рабочий стек

| Слой | Технологии |
|---|---|
| Backend | Python, FastAPI, Uvicorn, Pydantic |
| База данных | PostgreSQL, PostGIS, psycopg 3 |
| Frontend | Vue 3, Quasar, Vite |
| Карты | Leaflet/OpenStreetMap, Яндекс.Карты |
| Поиск | собственный движок `albion-search` |
| Умный чат | правила разбора + опциональная LLM (локальная или OpenAI-compatible) |
| Документы | DOCX, XLSX, PDF и другие форматы через LibreOffice |
| Развёртывание | Linux, HTTPS, nginx, systemd |
| AI-инструменты разработки | **Deepseek Flash, Qwen Coder, ChatGPT Luna** |

## Структура репозитория

| Путь | Что там |
|---|---|
| `backend/` | FastAPI-приложение, API, сервисы, чат, импорт, миграции |
| `frontend/` | Vue/Quasar: страницы, компоненты, карта, настройки |
| `engine/` | вендоренный поисковый движок и словари |
| `deploy/` | nginx, systemd и служебные скрипты |
| `doc/` | техническая документация |
| `scripts/` | генерация документации и вспомогательные скрипты |

## Быстрый старт

```bash
# Бэкенд
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --workers 6

# Фронтенд (dev, :9000, проксирует /api и /storage на :8000)
cd frontend && bun run dev
```

Секреты хранятся только в окружении: `.env` и `frontend/.env.local` не
коммитятся. Для фронтенда есть шаблон `frontend/.env.example`; переменные
бэкенда задаются в окружении процесса (systemd/оболочка).

## Проверки

```bash
# Тесты
.venv/bin/python -m pytest backend/tests

# Линт и сборка фронтенда
cd frontend && bun run lint:check && bun run build
```

## Шрифты и изображения

Веб-шрифты Inter, Roboto, PT Sans, Montserrat и Manrope хранятся локально
(`frontend/src/assets/fonts`) и распространяются по свободным лицензиям
SIL OFL 1.1 / Apache 2.0 — коммерческое использование разрешено. Тексты
лицензий лежат рядом со шрифтами и в `frontend/public/fonts/licenses/`.

Изображения на сайте — собственные материалы РА «Альбион» либо свободные
для коммерческого использования / используемые на основании подтверждённых
прав. Новые сторонние изображения добавляются только после проверки лицензии.
